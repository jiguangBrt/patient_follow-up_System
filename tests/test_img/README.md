# 门诊病历 OCR 测试图片

共 10 张虚构病历图片，图片内容保持原样，仅按“患者名-原始编号”重命名。

- `img/`：10 张 PNG 图片。
- `text/`：与图片同名的预设文本，供人工核对。
- `case_manifest.json`：全部病例的字段、文件路径及 SHA-256。
- `ocr-smoke-check.json`：生成时的 OCR 初步检查结果，文件路径已同步更新。
- `docs/`：两批图片各自的说明和生成提示词。
