## 如何测试

1. 打开医生工作台，左侧进入“病例识别与审核”。
2. 每次上传一张 PNG，确认它先进入未绑定患者的缓冲区，再点击“运行本机 OCR”。
3. 对照原图核对姓名、时间、性别、年龄与病历各字段；点击原文定位，特别检查长段落换行和多列中药。
4. 确认一项、修改一项、保留一项待确认，保存草稿后重新打开。此时不应自动创建或绑定患者。
5. 确认正确姓名后，明确选择已有患者或按该虚构姓名新建，再入档；正式档案只应显示已确认内容。

建议先测 01，再测 02–05。当前未提取到的字段可以继续待确认，不能为了填满表单把未知自动写成“无”。

## 附件说明

- 同名 `.txt`：图片生成时使用的预设文字，便于人工对照。
- `case_manifest.json`：场景、预设字段、文件尺寸、大小及 SHA-256。
- `generation-prompts.md`：完整生成提示词及生成方式。
- `ocr-smoke-check.json`：项目当前本机 OCR 的基础读取检查；不代表临床准确率验收。

图片生成功能可能对个别字形、空格或标点产生细微变化。预设文字不是逐像素核定的精确标注集，OCR 验收以最终图片中实际可见文字为准。

压缩包只包含本套虚构图片和上述说明，不包含用户最初提供的真实病例照片。
