# 医生团队与学生权限验收

本轮对应 #13 的账号与团队权限部分。医生和学生通过同一个“医生团队”入口登录，后端查询真实角色。学生仍归属一位医生，共用 `/doctor`、`/clinical` 工作台，所有数据接口校验身份与权限。

## 当前交互

- 学生与权限页默认只显示学生列表，右上角“刷新”旁是“新增学生”。新增学生、设置权限使用弹窗，不再展示授权记录入口。
- 点击学生行“设置权限”，只显示一次学生姓名，不再选择患者。权限覆盖所属医生当前及以后新增的全部患者，不涉及其他医生。
- 查看为默认勾选的复选框，可关闭；录入、审核分别设置，关闭查看时同时关闭其余权限。
- 开始和截止日期在同一行，按本机时区的完整自然日生效，截止日期当天仍有效。右侧“永久有效”勾选后禁用、置灰日期框，并保存为空日期范围，不使用虚构的远期到期时间。
- 备注位于最后，可留空；不再显示原来的时区与多条授权说明文字。
- 保存权限替换该学生的旧生效配置，保留历史与撤销人/时间。权限收窄不会残留旧的较宽授权。历史患者级授权保留原范围，直到医生在新版弹窗保存时改为全患者设置，迁移不会静默扩大历史授权。

## 真人验收

只使用虚构或去标识化资料。在两个独立窗口分别登录医生和学生。

1. 医生进入“设置 → 学生与权限”，点击“新增学生”。两次密码不一致应阻止提交；关闭或成功开通后密码清空并恢复隐藏。新学生尚未设置权限时不能查看患者。
2. 点击该学生行“设置权限”。检查姓名只显示一次、没有患者选择框、备注在最下方且非必填，查看默认勾选。
3. 不填备注，设置开始/截止日期并保存。学生刷新后应看到该医生的全部患者；医生再新增一名虚构患者，学生刷新也应看到。其他医生的患者详情和原件链接不能访问。
4. 再打开权限弹窗，勾选永久有效。日期框应置灰、无法编辑；保存后刷新，再打开设置权限时仍保持勾选状态。
5. 仅开查看：学生可查看患者与原件，不能上传、OCR、暂存或审核。开启录入后可为选择的患者上传原件、OCR 和暂存草稿；没有审核权限不能通过接口确认入档或驳回。医生可接手草稿完成入档。
6. 开启审核后，学生可在授权患者资料上确认入档；再取消审核并保存，原审核权限立即失效，旧设置进入历史记录。
7. 取消查看并保存，学生刷新后应没有可访问患者；原件、预览及审核直达接口均拒绝。限期配置到期后，也应拒绝后续请求。
8. 停用学生或所属医生，学生已有登录的后续请求也应拒绝。学生不能新建患者、管理二维码、开账号或再授权。
9. 管理员账号菜单仍区分医生/学生，学生列表显示所属医生。管理员不能直接读取病历接口。

本机隔离验收可双击 `医生学生权限测试.bat`，使用 `http://127.0.0.1:8013/` 与 `.local/issue_13_review/`；本机管理员 aaa001、医生 ddd001 的测试密码均为 12345678。这不是公网密码。
