# 青色主题与大字模式验收

日期：2026-10-27。功能基线见《当前已实现功能说明_2026-10-27.md》。本轮基于已有医生、学生功能继续改版，不以较旧 main 覆盖当前运行功能。

## 改动范围

- 使用本机 Kimi Code CLI 的 `kimi-code/k3.1-pro`，请求记录确认 `thinkingEffort=high`，完成初版；随后由 Codex 检查代码、浏览器布局及业务回归并修复问题。
- 统一登录、医生、管理员、学生权限、病例核对、患者中心、扫码建档和邀请认领共 8 个页面模板的青色主题。
- 默认正文 18px；大字模式正文 22px，表单、导航、表格、标题、占位文字同步放大。按钮及主要点击控件至少 44px；复选框采用 22px 方框和可点击标签。
- 各页面提供“大字模式”开关，刷新及跳页保持选择，多个已打开页面同步。浏览器不允许本地存储时仍可切换。
- 减少宣传插画、面包屑、重复标题及静态说明；保留须知全文、业务状态、权限、日期、错误与必要操作指引。
- 新增共享 `theme.css`、`accessibility.js`，不引入 CDN、第三方字体、前端框架或新运行依赖。

## 审核与修复

1. 初版病例页取消固定高度后，字段列表撑开整页，原件预览和底部操作无法保持在视口内。已恢复桌面固定工作区，合并顶部状态与字号开关所占行，保持字段独立滚动。标准和大字模式下，1366×768 的文档高度均为 768px；滚动字段时页面 scrollTop 为 0，底部按钮位置保持不变。
2. 修正患者工作区在部分断点重复保留侧栏宽度的问题。在 1024、1366、1700px 宽度核对侧栏右边界、名单起点和主区域位置，无重复偏移或页面横向溢出。
3. 修正手机弹窗关闭按钮继承全宽而挤压标题的问题；固定关闭按钮为 44px，并保留滚动表单和可见底部动作。
4. 调整手机权限日期框的字号、内边距和日历按钮，使同一行日期能完整显示；勾选永久后禁用日期，取消勾选恢复可编辑。
5. 修正登录输入框双重边框、占位文字仍为 12px、退出文字竖排、复选框被拉高等样式冲突；统一平板断点，避免病例按钮回落到旧版 11px。
6. 清空浏览器偏好时，同步重置其他已打开页面的大字开关。
